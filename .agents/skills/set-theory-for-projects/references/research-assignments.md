# Bounded Research Assignments

Use for independent technical-adjacency, shared-problem, complementary-capability or cross-ecosystem research after the Anchor Profile and Expansion Aim are settled. Keep small or coupled investigations with the main owner.

The coordinator maintains one candidate index and the main skill's total limits: 15 examined raw candidates, 5 qualifying finalists, or 2 distinct exhausted search paths. Reserve portions of the remaining raw-candidate budget before dispatch so concurrent workers cannot each consume the whole allowance. Workers return at their assigned checkpoint or budget; the coordinator reconciles duplicates and remaining capacity before assigning more. An exhausted worker allowance is not by itself an exhausted search path.

Each worker receives the Anchor evidence, Expansion Aim, necessary boundaries, relevant existing candidates, one bounded search path, allocated budget and stopping condition. It gathers bilateral evidence, proposed seams, counterevidence, maintenance concerns and unknowns. Return actual candidates examined, sources, duplicate matches and unchecked leads. A shared technology alone is a lead, not qualifying evidence. Workers neither change the aim nor create their own teams, prototypes or implementation tasks.

The coordinator matches candidate identities across paths, combines complementary evidence and applies the main skill's classification and maintenance gates. It alone counts qualifying finalists and exhausted distinct paths. Stop new searches when any global bound is reached, notify workers to stop expansion and collect already obtained results with their limits. Do not discard inconvenient negative evidence or use duplicate results as independent confirmation.

Send changed constraints or evidence to affected owners before further dependent research. On interruption, stop workers and preserve the index, consumed budget, completed paths and next action. A resumed run uses that checkpoint rather than receiving a fresh full allowance. If delegation is unavailable, use the same global boundary inline and report the execution actually performed.
