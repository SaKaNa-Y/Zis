# Hosted and Commercial Services

Read this profile for SaaS, external APIs, identity providers, observability products, content or communication services, and other vendor-operated products.

## Candidate Gates

A candidate must satisfy every applicable gate:

- performs the required user and repository job and supports load-bearing integrations, APIs, events, and workflows;
- satisfies data ownership, processing, retention, deletion, export, residency, privacy, security, and compliance requirements;
- supports required identity, access, roles, audit, single sign-on, provisioning, and organization boundaries;
- fits hard pricing, procurement, contract, support, and usage constraints supplied by the user;
- provides a credible continuity, migration, data export, rollback, replacement, and service-exit route.

Mark missing contract terms, unverifiable security claims, unclear data handling, and usage-dependent pricing Needs Evidence. Reject a candidate when required control or recoverability is absent.

## Compare Fit

Inspect:

- user experience, administration, onboarding, documentation, integration effort, API quality, SDKs, webhooks, quotas, and rate limits;
- roles, auditability, policy controls, SSO or provisioning, support response, uptime commitments, and incident communication;
- pricing by seat, usage, environment, data volume, retention, transfer, support, overage, and expected growth;
- vendor release and deprecation practice, export quality, integration stability, service continuity, and dependency on proprietary workflows;
- migration of configuration, users, permissions, automations, integrations, and historical data;
- coexistence, phased rollout, fallback operation, cancellation, deletion verification, and replacement cost.

Use current repository integrations, data flows, user roles, operational incidents, and volume evidence to establish needs. Use official product, API, pricing, contract, trust-center, data-processing, status, export, deletion, and changelog sources for candidate facts. Use credible incidents or adoption reports only for material behavior official sources cannot establish, and label the limits of that evidence.
