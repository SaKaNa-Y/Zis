# Zis 云端信息收集重构

状态：用户已确认首版范围并授权实施及创建正式 PR。当前在独立工作目录 `/workspace/Zis-capture`、分支 `feat/information-capture` 实施。协调者为本聊天；尚未部署、迁移生产数据库或创建浏览器定时任务。

## 已确认的目标与范围

- 基础设施只能免费，不开通付费升级或按量超额消费。现有免费方案不足时，评估后续迁往 Cloudflare；这不是现在就执行全量迁移的授权。用户此前接受使用指定模型的 Codex 额度，不据此另行购买模型 API。
- 将阅读入口改为按原文发布时间倒序的信息卡片流。
- 云端浏览来源并截图，通过登录后的 Zis 录入入口保存内容；用户也使用同一入口。
- 移除全部旧 RSS 来源配置，不保留停用列表，未来需要时重新添加。旧历史内容仍保留。OpenAI、Claude Code 官方博客作为新方案的来源另行配置，不继承旧 RSS 来源清单。
- 首批 X 来源：@OpenAI、@thsottiaux、@NFT_Chen、@Google、@AnthropicAI、@poteto。名单来自此前讨论，当前会话未重新核验账号身份。
- 指定账号的符合类型的内容全部收录，不按 AI 主题过滤。
- 收录原创、引用推文和推文串中的作者自我回复；排除纯转推和普通回复。
- 同一作者的推文串合并成一张卡片，内部按发布顺序展示；后续内容更新同一卡片。
- 推文串按首条推文发布时间排序，续更不使卡片上浮；卡片显示更新提示和最后更新时间。
- 推文保存完整原文、作者、原文发布时间、图片／截图及原帖链接，不翻译、不摘要、不改写。
- OpenAI、Claude Code 官方博客保存标题、作者、发布时间、完整正文、正文图片及原文链接；不翻译、不摘要。具体栏目尚待核验。
- 正文与图片自首次录入起保留七天；更新和补采不延长到期时间。
- 每天持续采集，七天是录入后的保留时长，不是按原文发布时间设置的采集窗口；不采用“只收最近七天发布的内容”的限制。
- 首次启用及新增来源时，默认从启用时开始收新增内容。用户明确要求补采时，可在来源页按北京时间日期提前所有已启用来源的起点（ADR-0026）；此操作不会自动采集，也不会改变去重及留存规则。
- 固定来源的新内容应在下一轮采集收录，正常情况下通常不超过十二小时，以发布后二十四小时内收录为目标。这是需要验证的时效目标，不是对访问失败、任务漏跑或平台延迟的无条件保证；异常须明确呈现并补采，不能记为没有新内容。
- 到期删除正文和图片后，长期保留原帖标识和到期时间作为最小去重记录，不保留正文、截图或摘要。这是用户明确接受的七天留存例外。
- 已到期推文串出现新续帖时，将新续帖作为新卡片收录，标注接续已过期推文串并附原串链接，不恢复旧正文或图片。新卡片从此次录入起保留七天。
- 部分内容不可访问时保存已取得的内容，明确标注不完整，后续补采。访问失败不能解释为没有新内容。
- 每轮早晚采集重试尚未补齐的内容；补齐后清除不完整标记，到七天期限即删除，不因补采延长。
- 每天北京时间 08:00、20:00 开始采集，完成后更新信息流；这是开始时间，不保证该时刻已采集完成。执行方式尚需验证；执行模型由用户指定。
- 首版在 Zis 展示最近采集时间、收录数量和失败来源；外部消息推送随后接入，不在首版创建外部通知。
- 博客正文保留标题层级、段落、列表、链接、引用、代码块、表格和图片，使用 Zis 的统一阅读样式，不复制来源网站的导航和广告。
- 与 skills 仓库的后续联动暂不纳入首版。
- 新版主界面为信息流、添加信息和来源管理。停用旧简报生成与兴趣筛选；旧简报、收藏、兴趣配置及历史数据先保留，不迁移进新信息流，也不在此次重构中直接删除。

## 当前实现与目标的差异

- 当前以 Signal、Admission 和 sealed Brief 为阅读核心；信息卡片流需要独立表达原始内容，不能直接视为 Brief Entry 的改名。
- Item 的 text 和 summary 存在 1,200 字符数据库限制，不能承载完整长文。
- 尚无图片上传／存储入口、X Transport 或推文串模型。
- 当前约三十天后只清理正文，长期保留元数据等；不符合新的七天正文与图片留存要求。
- 现有登录与会话能力可以作为录入入口的基础。
- ADR-0005 的剥离正文图片和富文本的选择需要重新讨论；保存全文和图片本身不要求保存来源 HTML。
- 新阅读流程不沿用 ADR-0006 的简报准入规则与 ADR-0007 的简报展示约束。旧功能退出主流程，历史数据保留。

## 证据与验收边界

此前聊天记录报告共享 Chrome 能显示公开 X 推文并截图。该历史结果不能证明本环境已经复测，也不能证明定时采集完整性；实现阶段须验证读取、截图、录入、去重、缺失提示和清理整条路径。

当前工具提供定时任务能力，但其接口没有模型选择字段或外部通知渠道字段。未来运行能否获得可用浏览器、复用登录状态及选择指定模型仍需实测；不得将提示词中的模型名称视为已完成模型选择。

设计讨论遵循 grill-with-docs，实施遵循用户指定的 implement-change。用户明确要求正式 PR，覆盖技能的默认草稿 PR 终点；本次不自动合并或部署。

## 当前实施约束与验收

- 为满足“只能免费”，首版实际采用现有 Neon 中的受限图片存储，不启用 R2 或 Vercel Blob。图片合计上限 128 MiB，数据库写入安全阈值 400 MiB；超过阈值明确失败，不调用收费后备服务。此选择替代下方早期对象存储建议。
- 用户已确认清理边界：七天到期即禁止读取正文和图片；每小时清理任务及采集写入事务删除已到期字节。任务延迟或失败允许物理删除延后，不能声称后台字节在精确到期时刻必定已删除。此边界需在交付与运维说明中保留。
- 验收覆盖完整原文、推文串更新、博客补采、来源启用时点、跨重试去重、过期续帖、SQL 事务回滚、图片容量边界、登录保护及到期图片 404。
- 当前技术验证使用 Node 22 和本地 PGlite；实际生产套餐、剩余额度、部署会话和定时浏览器可用性仍需上线阶段验证。
- 运行说明见 [capture-operations.md](../capture-operations.md)。

## 容量评估（2026-11-07，建议而非已选定的存储方案）

- 数据库建议保存正文、作者、时间、图片引用和去重记录；图片文件放对象存储，浏览器采集在独立云端执行，Vercel 承担网站及短时读写请求。
- 假设所有来源合计每天 60 条、每条正文及元数据 20 KB，七天约 8.4 MB，不含索引、旧数据与数据库维护开销。若每条两张 0.5 MB 图片，七天图片约 420 MB，但三十天约 3,600 次图片上传。该假设不是对账号实际发帖量的测量。
- 官方 Neon 定价页本次显示 Free 每项目 1 GB 数据库存储及每月 100 CU-hours；同时列出 5 GB 对象存储，现有账号的实际权益及接入方式尚未验证。历史项目运维记录在 2026-09-17 报告约 102 MB 存储和 Neon Free，不能当作当前余额。
- Vercel Blob 官方文档本次显示 Hobby 包含 1 GB-month 存储、10 GB 月传输和每月 2,000 次高级操作（上传、复制、列举等）。上述 60 条示例即使存储未超，也会超过上传操作额度；七天删除不抵扣已发生的月上传或传输量。
- 暂不因本估算升级套餐或创建存储。实施前需要确认账号套餐、实际余额、采集样本图片大小和对象存储操作/传输额度。旧历史数据和长期去重记录仍会占用数据库空间。

来源：[Neon pricing](https://neon.com/pricing)、[Vercel Blob usage and pricing](https://vercel.com/docs/vercel-blob/usage-and-pricing)。

### Cloudflare 备选

用户要求仅使用免费方案，并提出现有方案不满足时后续考虑迁往 Cloudflare。建议分别验证图片存储和应用迁移，不把全量迁移当成免费运行的保证。

- R2 Standard 免费包含每月 10 GB-month、100 万 Class A 和 1,000 万 Class B 操作，出口流量免费；它仍是超额计费产品，不能把免费额度等同于零费用硬上限。采用前必须验证可满足严格零支出约束的配置与访问控制。
- Workers/D1 可作为网站与数据的新落点，但当前 PostgreSQL 数据访问、Next.js 运行方式和原生 Argon2 登录依赖需要适配及实测，不是修改部署地址即可迁移。
- Cloudflare Browser Run 免费浏览器时间为每天十分钟，不能假定足以完成六个账号及博客的两轮采集；迁移网站不意味着将 Codex 执行或浏览器采集也迁入 Cloudflare。

参考：[R2 pricing](https://developers.cloudflare.com/r2/pricing/)、[Workers limits](https://developers.cloudflare.com/workers/platform/limits/)、[D1 limits](https://developers.cloudflare.com/d1/platform/limits/)、[Next.js on Workers](https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/)、[Browser Run pricing](https://developers.cloudflare.com/browser-run/pricing/)。
